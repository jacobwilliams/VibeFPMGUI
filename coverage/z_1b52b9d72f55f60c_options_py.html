1"""The project's configuration file (`vibefpmgui.build_configs.ConfigFile`): 

2which it is, and the GUI's options and New configuration's Build options in 

3it (see `vibefpmgui.project_options`): used while the project is open, 

4written back (when the window closes or another project is opened, if they 

5changed), and applied to the window when another project is opened. 

6 

7A project whose file holds options (it has one that can be read) uses them; 

8without, the app's settings as before (nothing is written in a project only 

9looked at). A file made while the project is open (its first configuration 

10saved) holds its options from then on. 

11 

12New configuration's Build options are one `Configuration`: the file's 

13"new_configuration", or, without options, the app's settings ("profile", 

14"compiler"… and the project's "features/<hash>").

31def project_key(manifest: Path, prefix: str) -> str: 

32 """The app's settings key for a project's ``prefix`` (its session, build 

33 configurations, features, test durations): "prefix/" and a short hash 

34 of its fpm.toml's path. (A name, not security: SHA-1 is fine.)""" 

35 digest = hashlib.sha1(str(manifest).encode(), usedforsecurity=False).hexdigest()[:16] 

36 return f"{prefix}/{digest}"
